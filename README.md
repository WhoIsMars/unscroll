# unscroll

Open source iOS app to use social networks without the endless scroll: keep DMs,
profiles you search for and content friends send you; drop Reels, Shorts, Explore,
suggested posts and ads. No subscription.

Status: early research. See [docs/PLAN.md](docs/PLAN.md) (Italian).
